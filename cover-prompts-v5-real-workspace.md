# AI 设计魔法师 · 6 张服务封面提示词 v5（真实办公桌面 + 屏幕内作品）

> 参考图风格：真实现代办公桌面场景，核心视觉焦点是**显示器屏幕内展示的类目作品**（剪辑时间轴、3D 模型、UI 设计稿、产品图库等）。
> 适用于 Nano Banana / Gemini / Midjourney / Flux / 可灵 / Veo 等。

## 风格要点

- **有真实工作场景**：桌、显示器、键盘、鼠标、手、台灯/补光灯、相机、绿植、色卡等。
- **视觉焦点在红圈区域**：即屏幕内展示的内容，必须一眼看出是哪类设计。
- **无悬浮魔法、无全息玻璃、无暗色魔法光流**。
- **屏幕内容无文字、无 logo、无水印**，但要有该类目的典型视觉特征。
- 官网紫 `#7621B0` / 绿 `#1FD66E` 只作为桌面小点缀（显示器背光灯带、线缆、小物件），不做主视觉。

## 颜色锚点

| 用途 | HEX |
|---|---|
| 背景/环境 | 明亮白/浅灰/木色桌面 |
| 强调紫（点缀） | `#7621B0` |
| 点缀绿（点缀） | `#1FD66E` |
| 屏幕背光/氛围 | 柔和冷白/淡紫 |

## 负面提示词（必加）

```
no text, no letters, no words, no typography, no logo, no watermark, no signature, no readable characters, no floating holographic screens, no magical energy ribbons, no dark studio background, no purple-green gradient background, no cartoon, no flat vector illustration, no clipart, no oversaturated colors
```

## 使用建议

1. **先跑风格锚**：第一张确认"明亮办公桌 + 显示器屏幕 + 浅景深"基调。
2. **续图统一**：后面 5 张用 `Same workspace style as previous...` 开头，保持桌子、光线、配饰不变，只换屏幕里的作品类型。
3. **屏幕内容要典型**：每个类目让屏幕出现一眼可辨的代表元素（时间轴=视频，3D 模型=建模，UI 网页=前端，产品图库=电商，海报/Logo=平面，景观渲染=景观）。
4. **屏幕无文字 but 有内容**：提示里强调 `blurred UI, no readable text`，避免 AI 在屏幕上写乱码假字。
