# 高祥 · AI设计魔法师 — 「作品预览」板块 8 张成功作品展示动态图提示词
## 用途：http://localhost:9111/#marquee-section 作品预览滚动栏（双行卡片，约 16:10）
## 定位：给顾客看的"专业项目交付体系"展示 —— 每张 = 一个类目的一组关联成品，体现专业度
## 风格：纯白/无场景背景 + 紫 #7621B0 / 绿 #1FD66E 点缀 + 成体系交付物矩阵 + 科技艺术感

> 关键要求：画面里**只有作品本身，不带任何拍摄场景**（无工作室/桌子/手/显示器外框/环境）。
> 每张 = 该类目的**一个真实项目的一组关联交付物**，排布成专业矩阵，让顾客一眼看懂"这人能交付一整套"。
> 例如电商：同一产品的 海报 + 主图 + 多 SKU + 详情页 同框展示。
> 作品内容清晰可辨专业细节；避免真实可读文字/品牌 logo（防侵权与杂乱）。
> 动态 = GIF/短视频，轻柔循环：矩阵内元素轻微位移/缩放/高光游走，体现"活的专业作品墙"。
> 比例：16:10（贴近板块卡片 420×270）。无 logo、无真实可读文字。

## 使用建议
1. 先跑「统一风格锚」定调，后 7 张用 `Same work-only, plain-white style as the previous image` 续图，只换该类目的交付物组合。
2. 生成 3–5 秒循环短片（可灵 / Veo / Runway）→ 压成 GIF（≤5MB）。
3. 传到后台 `/admin`「作品预览」或直接写进 `worksGallery`，板块自动双行滚动，无需改代码。
4. MCU / FDE 若也要进作品预览，可按同"交付物矩阵"风格补：MCU=同一开发板的 原理图+PCB+焊接成品+固件界面；FDE=同一部署的 拓扑图+状态面板+终端日志+上线截图。
